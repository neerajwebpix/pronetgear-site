About this item

This listing covers 3 units of the TP-Link TL-R470T+ Router. The stock was used at corporate events and is now surplus from our own event inventory, so you are buying from the team that deployed it.

Multi-WAN load-balance routers combine several internet lines so traffic is shared and one line failing does not take the site offline.

Where it is useful

Typical ways buyers put a load-balance router to work:

  • Events and venues using more than one ISP line
  • Offices that want a backup connection
  • Temporary sites bonding several broadband links
  • Branch networks with VPN needs

Before you buy: what to check

Used equipment is easy to get right if you check a few things first:

  • Number of WAN ports and how many lines you plan to use
  • Firmware version and management access
  • Power adapter and rack-mount hardware
